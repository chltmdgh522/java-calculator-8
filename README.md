## 구현할 기능 목록

- [ ] **입력 처리 기능**
    - [ ] 사용자의 문자열 입력을 받는다.
    - [ ] 입력값이 비어 있거나 `null`인 경우 결과값으로 `0`을 반환한다.

- [ ] **기본 구분자(, : ) 파싱 기능**
    - [ ] 문자열에서 쉼표(`,`) 또는 콜론(`:`)을 기준으로 숫자를 분리한다.
    - [ ] 분리된 문자열을 정수형으로 변환한다.
    - [ ] 변환된 숫자들의 합을 계산하여 반환한다.

- [ ] **커스텀 구분자 처리 기능**
    - [ ] 문자열이 `"//"`로 시작하는 경우 커스텀 구분자를 추출한다.
    - [ ] `"//"`와 `"\n"` 사이의 문자를 커스텀 구분자로 인식한다.
    - [ ] 커스텀 구분자를 기준으로 숫자를 분리하고 합산한다.
    - [ ] 예: `"//;\n1;2;3"` → 구분자 `;` → 결과 `6`

- [ ] **예외 처리 기능**
    - [ ] 음수 또는 숫자가 아닌 값이 포함된 경우 `IllegalArgumentException`을 발생시킨다.
    - [ ] 예외 발생 시 에러 메시지를 출력하고 프로그램을 종료한다.

- [ ] **출력 기능**
    - [ ] 계산 결과를 `"결과 : {sum}"` 형식으로 출력한다.

- [ ] **테스트 코드 작성**
    - [ ] 빈 문자열 입력 시 `0` 반환 테스트
    - [ ] 기본 구분자(쉼표, 콜론) 입력 테스트
    - [ ] 커스텀 구분자 입력 테스트
    - [ ] 잘못된 입력(음수, 문자 등) 테스트

## Commit Convention

> AngularJS Git Commit Message Conventions을 따릅니다.

| Type         | Description                         |
|--------------|-------------------------------------|
| **feat**     | 새로운 기능 추가 (feature)                 |
| **fix**      | 버그 수정 (bug fix)                     |
| **docs**     | 문서 수정 (README 등)                    |
| **style**    | 코드 포맷 변경 (세미콜론 누락, 공백 등 — 기능 영향 없음) |
| **refactor** | 코드 리팩토링 (기능 변경 없이 구조 개선)            |
| **test**     | 테스트 코드 추가 또는 수정                     |
| **chore**    | 빌드, 패키지 관리, 유지보수 등의 기타 작업           |
